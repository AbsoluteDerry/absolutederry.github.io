ABSOLUTEDERRY BLOG — GITHUB UPLOAD

1. Open the AbsoluteDerry/absolutederry.github.io repository on GitHub.
2. Click Add file > Upload files.
3. Drag ALL files from this folder into GitHub's upload area.
4. Commit directly to the main branch.
5. Open Settings > Pages.
6. Choose Deploy from a branch, then main and /(root), and save.
7. Open absolutederry.github.io after GitHub finishes deployment.

Important: Upload the CONTENTS of this folder, not the folder itself.
